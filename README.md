# Sales & Revenue Analysis Dashboard

# Project Overview
This project presents an interactive Sales & Revenue Analysis Dashboard developed using Microsoft Power BI. The dashboard helps analyze business performance through key performance indicators (KPIs), sales trends, product performance, and regional insights.

# Objectives
- Analyze overall sales and revenue performance.
- Track important business KPIs.
- Understand monthly revenue trends.
- Identify top-performing products.
- Analyze sales performance across regions.
- Enable interactive analysis using filters and slicers.

# Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

# Dashboard Features
- KPI Cards for business performance monitoring.
- Monthly Revenue Analysis.
- Sales by Category.
- Top Performing Product Analysis.
- Sales by Region.
- Interactive Date Slicer.

# Key Business Insights
The dashboard provides a consolidated view of sales and revenue performance, helping users identify trends, compare categories, and understand product and regional performance.
